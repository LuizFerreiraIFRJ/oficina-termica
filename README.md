## Como usar

- Na primeira vez, o navegador baixa o Python (Pyodide) e as bibliotecas: precisa de internet e leva de 1 a 2 minutos.
- Executar tudo: menu **Run › Run All Cells**.
- Tarefas: complete a célula marcada com ✍️ e rode. A resposta fica na célula logo abaixo, recolhida; para abrir, clique nos três pontinhos (•••).
- O que você muda fica salvo só neste navegador. Para levar o notebook: **File › Download**.
- Os mesmos arquivos `.ipynb` também abrem no Google Colab e no Jupyter instalado.
